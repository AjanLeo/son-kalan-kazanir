# SON KALAN KAZANIR — Android proje başlangıcı

Godot 4.3 / GL Compatibility. Bu depo ilk oynanabilir temel sürümü içerir: 3D parkur, oyuncu ve botlar, dokunmatik kontroller, üç turlu eleme akışı ve yerel kayıt.

Not: Bu sürüm nihai oyun değildir. Talep edilen sekiz harita, kostüm mağazası, görevler, sesler ve cihaz testleri henüz tamamlanmamıştır.

GitHub Actions, Android debug APK üretmeyi dener. Başarılı derlemenin APK'sı Actions > Artifacts bölümünde bulunur.
